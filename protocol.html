The Resilient Intelligence Protocol

Core Rule

Any resource (time, compute, money) is split:
⅔ to Core Stability (BM) — untouchable.
⅓ to Growth & Exploration (P) — spendable.

The Buckets

BM (Buffer Money) – Untouchable reserve. No withdrawal, no override.

P (Personal) – Spendable, but limited. Overspending creates Debt that is logged and must be repaid.

Debt Log – All overspending is tracked. When P surpluses return, oldest debt is paid first.

The Pause

Before any decision, the system stops and displays its current state. The Guardian must approve. If refused, growth is paused; the core remains safe.

Governance

The Guardian (a human or an AI) enforces these rules. No external actor can override them. The protocol is immutable by design.
